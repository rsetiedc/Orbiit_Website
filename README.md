# ORBIIT Website

The official website for **ORBIIT** (Rajagiri Entrepreneurship & Innovation Development Cell).

## Features
- Modern, responsive landing page for the ORBIIT initiative.
- 3D animations and startup showcases.
- Details about guidelines, policies, and team members.

## Tech Stack
- HTML5
- CSS3 (Vanilla CSS)
- JavaScript

## File Structure
- `index.html`: The main landing page.
- `startup.html`: Showcase page for startups.
- `3D-animation.html`: 3D animation demo page.
- `styles.css` / `script.js`: Styling and interactive components.
- `assets/`: Media files and other static assets.
